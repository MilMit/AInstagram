# AInstagram — Legacy Metadata

This is a legacy repository under the [MilMit GitHub organization](https://github.com/MilMit).

## Repository contents

- `Ainsta.html` — a small historical version/configuration text file (it is not an HTML application).
- `is_verified.json` — a legacy JSON data file.

**Scope:** This repository currently contains metadata files only. It does not provide the source code or an installable release of an Instagram client.

For actively maintained public software and documentation, see [MilMit's repositories](https://github.com/orgs/MilMit/repositories).
